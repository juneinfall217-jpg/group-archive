# 怎么把资料库变成一个可分享链接

这个资料库是静态网页，发布后别人只需要打开一个链接就能看，不需要下载压缩包。

## 推荐方式

### 方式一：Netlify 拖拽发布

适合不想折腾代码仓库的小组。

1. 打开 Netlify
2. 登录账号
3. 找到拖拽上传网站文件夹的入口
4. 把整个资料库文件夹上传
5. Netlify 会生成一个网址
6. 把这个网址发给组员

适合：快速分享、临时项目、小组作业。

### 方式二：GitHub Pages

适合后续还会持续更新资料的小组。

1. 新建一个 GitHub 仓库
2. 上传这些文件：
   - `index.html`
   - `styles.css`
   - `app.js`
   - `data.js`
   - `images/`
3. 在仓库设置里开启 Pages
4. 选择主分支作为发布来源
5. GitHub 会生成一个网页链接

适合：长期维护、多人协作、后续继续补充资料。

### 方式三：Cloudflare Pages

适合想要访问速度稳定、后面可能绑定自定义域名的小组。

1. 登录 Cloudflare Pages
2. 新建 Pages 项目
3. 上传这个资料库文件夹，或连接 GitHub 仓库
4. 发布后复制生成的网址

适合：正式一点的项目展示。

## 分享前要注意

如果老师分享的图片资料涉及版权、课程内部资料、同学照片、个人信息，建议先确认这些内容是否能公开发布。

如果只想给小组内部看，可以：

- 只发给小组成员
- 使用平台的访问限制功能
- 或先做一个不公开的仓库/项目

## 发布前检查

发布前确认这些文件都在同一个文件夹里：

```text
index.html
styles.css
app.js
data.js
images/
```

如果网页打开后图片不显示，通常是 `data.js` 里的图片路径和 `images` 文件夹里的真实路径不一致。
